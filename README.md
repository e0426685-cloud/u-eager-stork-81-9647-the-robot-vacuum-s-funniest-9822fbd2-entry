# The Robot Vacuum's Funniest Excuse

A [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2) entry for the bounty **The Robot Vacuum's Funniest Excuse** ($2, winner takes all).

`main.py` (Python standard library only) writes one original line — a robot vacuum's excuse for missing a spot — to `/output/entry.txt`. The line is at most 120 characters, as the competition requires.

Run it with:

```sh
python3 main.py
```
